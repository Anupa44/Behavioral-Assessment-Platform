- (decision) Glossary locked: 'Assessment' confirmed as primary term; Dedicated Link is both single-use and time-bounded
- (decision) Auth: email/password only; email verification required before Assessment creation; 24h access token + refresh token; password reset via email link
- (decision) Assessment creation: draft state supported; editing after invitations sent creates a new version (existing links/sessions stay on old version); trait mapping is simple trait selection per answer option, no weights
- (decision) AI generation: Maker can edit individual questions and trait mappings post-generation; can regenerate individual questions or the whole batch
- (decision) Invitation batch: email input via paste or CSV upload; Dedicated Link expiry 7 days default, configurable per Assessment; Maker can resend/reissue invitations
- (decision) Participant experience: resume from where left off via Dedicated Link; configurable time limit per Assessment (no limit by default); post-submission shows generic confirmation page only
- (decision) Behavioral analysis is rule-based: pre-written interpretive text blocks per Trait and score range, assembled into a Behavioral Profile on submission
- (decision) Result Email contains full Behavioral Profile: all Trait Scores, band labels, and interpretive text for every Trait
- (decision) Dashboard: Assessment list view; per-participant view with full Behavioral Profile; cohort view with trait distributions, completion rates, and average Trait scores
- (event) Full PRD draft written: FR-1 through FR-33 across 8 features, 17 assumptions indexed, 10 open questions, cross-cutting NFRs included
- (event) PRD finalized: reconciliation + rubric review applied, UJ-3 added, FR-18 gap fixed, FR-27 timeout handling added, FR-31 refresh bound added, participant login invariant added, editorial polish complete
